Keypad Security System

A small alarm system that guards a doorway. It watches for motion with an ultrasonic sensor, gives you 10 seconds to type your code, then sounds a siren. It also has a servo "lock", lockouts for wrong guesses, and a code you can change from the keypad.

01What it does

Everything the finished system can do.

Motion detection

An HC-SR04 checks for anything closer than 20 cm, 10 times a second. It needs 3 close readings in a row, so a single glitch won't set it off.

Exit & entry delays

You get 5 seconds to leave after arming. When motion is seen, you get 10 seconds to type your code before the siren, with warning beeps that speed up.

Siren & sound effects

A rising and falling 600–1600 Hz siren, plus key clicks, a happy chirp for a right code and a low buzz for a wrong one.

Lockout on wrong codes

Three wrong codes lock the keypad for 10 s, then 30 s, then 60 s. The sensor and siren keep working while it's locked.

Changeable code

Press A while disarmed to change the code. It's saved in EEPROM, so it survives a power cut. Forgot it? Hold the button while powering on.

Alarm handling

A second "alert code" stops the siren and asks whether it was a false alarm or a real threat. A servo acts as a lock: closed when armed, open otherwise.

04How to use it

The codes, the keys and what each one does.

Arm / disarm code

1234

Arms and disarms the system, and stops the entry countdown. You can change it with A.

Alert code

2468

Only works while the siren is going. Opens the "False alarm or real threat?" choice.

Change the codes before you share thisEveryone reading this page knows 1234 and 2468. Change the arm code with A, and change ALERT_PASSWORD in the code.

Keys

KeyWhat it does
0–9Type a code (up to 8 characters). The screen shows Code: 12 as you type.
#Submit the code.
*Clear what you typed. While changing the code, pressing it with nothing typed cancels.
AWhile disarmed: start changing the arm code.
1 / 2After the alert code: 1 = false alarm, 2 = real threat.
ButtonWhile disarmed: arm right away. During the alarm: asks for the arm code to reset. Otherwise it does nothing.
Button held at power-onResets a forgotten code to 1234.

A typical day

  1. Power on. The screen says Starting..., then the system arms itself. You have 5 seconds to step away.
  2. Someone walks in. The screen shows Motion! 10s left, the red LED blinks, and it beeps once a second, then faster for the last 3 seconds.
  3. You type 1234# in time. Access Granted / System Disarmed. The servo opens.
  4. Or nobody types the code. The siren starts and the red LED stays on. Type 2468#, then 1 (false alarm) or 2 (real threat). Both disarm the system.
  5. Leaving again? Type 1234# or press the button to arm.

Changing the code

  1. Make sure the system is disarmed, then press A.
  2. Type the old code and press #.
  3. Type the new code (4–8 digits) and press #.
  4. Type it again and press #. You'll see Code Saved!.

06How it thinks

The system is always in exactly one state. Each arrow is the thing that moves it to the next one.

In the code, these are the values of enum State. "Change code" is really three states in a row (CHANGE_OLD, CHANGE_NEW, CHANGE_REPEAT), one for each step.

#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <Servo.h>
#include <Keypad.h>
#include <EEPROM.h>

// Pins
const int trigPin   = 10;
const int echoPin   = 11;
const int buzzer    = 12;
const int servoPin  = A3;
const int buttonPin = A2;
const int greenLED  = A0;
const int redLED    = A1;

// Settings
const int  TRIGGER_DISTANCE_CM = 20;
const byte READINGS_TO_TRIGGER = 3;          // close readings in a row before alarm
const unsigned long SENSOR_INTERVAL = 100;   // ms between sensor pings
const unsigned long EXIT_DELAY      = 5000;  // time to step away after arming
const unsigned long ENTRY_DELAY     = 10000; // time to type the code after motion
const unsigned long ENTRY_TIMEOUT   = 8000;  // clear half-typed code after this
const byte MAX_ATTEMPTS = 3;
const unsigned long LOCKOUT_TIMES[] = {10000, 30000, 60000};  // gets longer each time
const byte LOCKOUT_LEVELS = 3;
const byte MIN_CODE_LEN = 4;
const byte MAX_CODE_LEN = 8;
const bool HIDE_CODE = false;                // true = show **** instead of digits

// EEPROM layout for the saved code
const int  EE_MAGIC_ADDR = 0;
const byte EE_MAGIC      = 0x42;
const int  EE_LEN_ADDR   = 1;
const int  EE_CODE_ADDR  = 2;

LiquidCrystal_I2C lcd(0x27, 16, 2);
Servo myServo;

// Keypad
const byte ROWS = 4;
const byte COLS = 4;
char keys[ROWS][COLS] = {
  {'1','2','3','A'},
  {'4','5','6','B'},
  {'7','8','9','C'},
  {'*','0','#','D'}
};
byte rowPins[ROWS] = {9, 8, 7, 6};
byte colPins[COLS] = {5, 4, 3, 2};
Keypad keypad = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS);

// Passwords
const String DEFAULT_ARM_PASSWORD = "1234";
const String ALERT_PASSWORD       = "2468";
String armPassword = DEFAULT_ARM_PASSWORD;   // loaded from EEPROM at startup
String entered = "";
String newCode = "";

// System states
enum State { DISARMED, ARMED, ENTRY, ALERT, CONFIRM, CHANGE_OLD, CHANGE_NEW, CHANGE_REPEAT };
State state = ARMED;

bool resetRequested = false;   // button pressed during alarm -> arm code resets it
byte failedAttempts = 0;
byte lockoutLevel = 0;
bool lockedOut = false;
unsigned long lockoutStart = 0;
unsigned long lockoutDuration = 0;
unsigned long lastKeyTime = 0;
unsigned long armedAt = 0;
unsigned long entryStart = 0;
unsigned long alertStart = 0;
unsigned long lastSensorTime = 0;
byte closeReadings = 0;
unsigned long messageStart = 0;
unsigned long messageDuration = 0;   // 0 = no temporary message on screen
bool notifiedPending = false;
bool lastButtonState = HIGH;

// ---------- Sounds ----------

struct Note { unsigned int freq; unsigned int ms; };
const Note CLICK[] = {{2000, 30}};
const Note GOOD[]  = {{1500, 80}, {2000, 80}, {2600, 120}};
const Note BAD[]   = {{400, 200}, {250, 400}};
const Note DENY[]  = {{200, 80}};
const Note WARN[]  = {{1000, 100}};

const Note* melody = nullptr;
byte melodyLen = 0;
byte melodyIndex = 0;
unsigned long noteStart = 0;
bool sirenOn = false;
unsigned long lastSirenUpdate = 0;
unsigned long lastWarnBeep = 0;

#define PLAY(m) playSound(m, sizeof(m) / sizeof(m[0]))

void playSound(const Note* m, byte len) {
  melody = m;
  melodyLen = len;
  melodyIndex = 0;
  noteStart = millis();
  tone(buzzer, m[0].freq, m[0].ms);
}

// ---------- Setup & loop ----------

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(buzzer, OUTPUT);
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(greenLED, OUTPUT);
  pinMode(redLED, OUTPUT);

  lcd.init();
  lcd.backlight();
  myServo.attach(servoPin);
  myServo.write(0);
  delay(10);

  // Hold the button while powering on to reset a forgotten code
  if (digitalRead(buttonPin) == LOW) {
    armPassword = DEFAULT_ARM_PASSWORD;
    saveCode();
    printLine(0, "Code Reset To");
    printLine(1, "Default: " + DEFAULT_ARM_PASSWORD);
    delay(2000);
  } else {
    loadCode();
  }

  printLine(0, "Security System");
  printLine(1, "Starting...");
  delay(2000);   // the only other blocking delay, at boot

  lastButtonState = digitalRead(buttonPin);
  setState(ARMED);
  showStatus();
}

void loop() {
  checkButton();
  checkKeypad();
  checkSensor();
  updateEntryDelay();
  updateSound();
  updateLEDs();
  updateScreenTimers();
}

void setState(State s) {
  bool sirenState = (s == ALERT || s == CONFIRM);
  if (sirenOn && !sirenState) {
    noTone(buzzer);
    sirenOn = false;
  }
  if (s == ALERT && state != CONFIRM) {
    alertStart = millis();
    resetRequested = false;
  }
  if (s == ARMED) armedAt = millis();
  if (s == ENTRY) {
    entryStart = millis();
    lastWarnBeep = 0;
  }

  state = s;
  entered = "";
  closeReadings = 0;
  myServo.write((s == ARMED || s == ENTRY) ? 0 : 90);
}

bool isChangeState() {
  return state == CHANGE_OLD || state == CHANGE_NEW || state == CHANGE_REPEAT;
}

// ---------- Inputs ----------

void checkButton() {
  static unsigned long lastChange = 0;
  bool reading = digitalRead(buttonPin);
  if (reading != lastButtonState && millis() - lastChange > 50) {
    lastChange = millis();
    lastButtonState = reading;
    if (reading == LOW) {
      onButtonPress();
    }
  }
}

void onButtonPress() {
  switch (state) {
    case DISARMED:
      // Arming is always safe, so no code needed
      setState(ARMED);
      PLAY(GOOD);
      showMessage("Button Pressed", "System Armed", 1500);
      break;
    case ALERT:
      // Silencing the alarm needs the arm code
      resetRequested = true;
      entered = "";
      PLAY(CLICK);
      showStatus();
      break;
    default:
      PLAY(DENY);
      showMessage("Button Locked", "Use the Code", 1500);
      break;
  }
}

void checkKeypad() {
  char key = keypad.getKey();
  if (!key) return;

  if (lockedOut) {
    PLAY(DENY);
    return;
  }

  lastKeyTime = millis();
  PLAY(CLICK);

  if (state == CONFIRM) {
    handleConfirmation(key);
  } else {
    handleCodeKey(key);
  }
}

void checkSensor() {
  if (state != ARMED) return;
  if (millis() - armedAt < EXIT_DELAY) return;
  if (millis() - lastSensorTime < SENSOR_INTERVAL) return;
  lastSensorTime = millis();

  long distance = getDistance();
  if (distance > 0 && distance < TRIGGER_DISTANCE_CM) {
    closeReadings++;
    if (closeReadings >= READINGS_TO_TRIGGER) {
      setState(ENTRY);
      messageDuration = 0;
      showStatus();
    }
  } else {
    closeReadings = 0;
  }
}

long getDistance() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  long duration = pulseIn(echoPin, HIGH, 25000);
  if (duration == 0) return -1;   // no echo
  return duration / 58;           // cm
}

// ---------- Keypad logic ----------

void handleCodeKey(char key) {
  if (key == '*') {
    if (entered.length() == 0 && isChangeState()) {
      setState(DISARMED);
      showMessage("Code Change", "Cancelled", 1500);
      return;
    }
    entered = "";
    showStatus();
    return;
  }

  if (key == 'A' && state == DISARMED && entered.length() == 0) {
    setState(CHANGE_OLD);
    messageDuration = 0;
    showStatus();
    return;
  }

  if (key == '#') {
    if (entered.length() > 0) submitCode();
    return;
  }

  if (entered.length() < MAX_CODE_LEN) {
    entered += key;
    messageDuration = 0;
    notifiedPending = false;
    showStatus();
  }
}

void submitCode() {
  String code = entered;
  entered = "";

  switch (state) {
    case ALERT:
      if (code == ALERT_PASSWORD) {
        codeAccepted();
        setState(CONFIRM);
        showStatus();
      } else if (resetRequested && code == armPassword) {
        codeAccepted();
        setState(ARMED);
        showMessage("Alarm Reset", "System Armed", 1500);
      } else {
        wrongCode();
      }
      break;

    case DISARMED:
    case ARMED:
    case ENTRY:
      if (code == armPassword) {
        bool arming = (state == DISARMED);
        codeAccepted();
        setState(arming ? ARMED : DISARMED);
        showMessage("Access Granted", arming ? "System Armed" : "System Disarmed", 1500);
      } else {
        wrongCode();
      }
      break;

    case CHANGE_OLD:
      if (code == armPassword) {
        codeAccepted();
        setState(CHANGE_NEW);
        showStatus();
      } else {
        wrongCode();
      }
      break;

    case CHANGE_NEW:
      if (code.length() < MIN_CODE_LEN || !allDigits(code)) {
        PLAY(BAD);
        showMessage("Use 4-8 Digits", "Try Again", 1500);
      } else if (code == ALERT_PASSWORD) {
        PLAY(BAD);
        showMessage("Can't Use That", "Try Again", 1500);
      } else {
        newCode = code;
        setState(CHANGE_REPEAT);
        showStatus();
      }
      break;

    case CHANGE_REPEAT:
      if (code == newCode) {
        armPassword = newCode;
        saveCode();
        PLAY(GOOD);
        setState(DISARMED);
        showMessage("Code Saved!", "New Code Active", 2000);
      } else {
        PLAY(BAD);
        setState(CHANGE_NEW);
        showMessage("No Match", "Start Again", 1500);
      }
      break;

    default:
      break;
  }
}

void handleConfirmation(char key) {
  if (key == '1') {
    setState(DISARMED);
    PLAY(GOOD);
    showMessage("False Alarm", "System Disarmed", 2000);
  } else if (key == '2') {
    setState(DISARMED);
    showMessage("Calling 911...", "", 2000);
    notifiedPending = true;   // shows "Authorities Notified" next
  }
}

void codeAccepted() {
  failedAttempts = 0;
  lockoutLevel = 0;
  PLAY(GOOD);
}

void wrongCode() {
  failedAttempts++;
  PLAY(BAD);
  if (failedAttempts >= MAX_ATTEMPTS) {
    failedAttempts = 0;
    lockoutDuration = LOCKOUT_TIMES[lockoutLevel];
    if (lockoutLevel < LOCKOUT_LEVELS - 1) lockoutLevel++;
    lockedOut = true;
    lockoutStart = millis();
    if (isChangeState()) setState(DISARMED);
    showMessage("Too Many Tries", "Locked " + String(lockoutDuration / 1000) + " sec", 2000);
  } else {
    showMessage("Wrong Password", "Tries: " + String(failedAttempts) + "/" + String(MAX_ATTEMPTS), 1500);
  }
}

bool allDigits(const String &s) {
  for (unsigned int i = 0; i < s.length(); i++) {
    if (s[i] < '0' || s[i] > '9') return false;
  }
  return true;
}

// ---------- Saved code (EEPROM) ----------

void loadCode() {
  if (EEPROM.read(EE_MAGIC_ADDR) != EE_MAGIC) return;   // nothing saved yet
  byte len = EEPROM.read(EE_LEN_ADDR);
  if (len < MIN_CODE_LEN || len > MAX_CODE_LEN) return;
  String code = "";
  for (byte i = 0; i < len; i++) {
    code += (char)EEPROM.read(EE_CODE_ADDR + i);
  }
  if (allDigits(code)) armPassword = code;
}

void saveCode() {
  EEPROM.update(EE_LEN_ADDR, armPassword.length());
  for (byte i = 0; i < armPassword.length(); i++) {
    EEPROM.update(EE_CODE_ADDR + i, armPassword[i]);
  }
  EEPROM.update(EE_MAGIC_ADDR, EE_MAGIC);
}

// ---------- Alarm, sound & LEDs ----------

void triggerAlert() {
  setState(ALERT);
  notifiedPending = false;
  showMessage("!! ALERT !!", "Intruder Alert!", 3000);
}

void updateEntryDelay() {
  if (state != ENTRY) return;
  unsigned long elapsed = millis() - entryStart;
  if (elapsed >= ENTRY_DELAY) {
    triggerAlert();
    return;
  }
  // Warning beeps, faster in the last 3 seconds
  unsigned long beepEvery = (ENTRY_DELAY - elapsed < 3000) ? 250 : 1000;
  if (melody == nullptr && millis() - lastWarnBeep >= beepEvery) {
    lastWarnBeep = millis();
    PLAY(WARN);
  }
}

void updateSound() {
  // Siren: sweeps 600 Hz -> 1600 Hz -> 600 Hz every second
  if (state == ALERT || state == CONFIRM) {
    melody = nullptr;
    if (millis() - lastSirenUpdate >= 10) {
      lastSirenUpdate = millis();
      unsigned long phase = (millis() - alertStart) % 1000;
      unsigned int freq = (phase < 500) ? 600 + phase * 2 : 600 + (1000 - phase) * 2;
      tone(buzzer, freq);
      sirenOn = true;
    }
    return;
  }

  // Short sound effects
  if (melody != nullptr && millis() - noteStart >= melody[melodyIndex].ms + 20) {
    melodyIndex++;
    if (melodyIndex >= melodyLen) {
      melody = nullptr;
    } else {
      noteStart = millis();
      tone(buzzer, melody[melodyIndex].freq, melody[melodyIndex].ms);
    }
  }
}

void updateLEDs() {
  bool blink = (millis() / 250) % 2;
  bool red = (state == ALERT || state == CONFIRM) || (state == ENTRY && blink);
  digitalWrite(greenLED, state == ARMED ? HIGH : LOW);  // Armed = green
  digitalWrite(redLED, red ? HIGH : LOW);               // Entry = blinking red, Alert = red
  // Disarmed = both off
}

// ---------- Screen ----------

// Prints a full 16-char line (pads with spaces, no flicker from lcd.clear())
void printLine(byte row, const String &text) {
  lcd.setCursor(0, row);
  lcd.print(text);
  for (int i = text.length(); i < 16; i++) {
    lcd.print(' ');
  }
}

void showMessage(const String &line1, const String &line2, unsigned long ms) {
  printLine(0, line1);
  printLine(1, line2);
  messageStart = millis();
  messageDuration = ms;
}

unsigned long entrySecsLeft() {
  unsigned long elapsed = millis() - entryStart;
  if (elapsed >= ENTRY_DELAY) return 0;
  return (ENTRY_DELAY - elapsed + 999) / 1000;
}

unsigned long lockSecondsLeft() {
  unsigned long elapsed = millis() - lockoutStart;
  if (elapsed >= lockoutDuration) return 0;
  return (lockoutDuration - elapsed + 999) / 1000;
}

String topLine() {
  switch (state) {
    case CONFIRM:       return "1 = False Alarm";
    case CHANGE_OLD:    return "Change: Old Code";
    case CHANGE_NEW:    return "Change: New Code";
    case CHANGE_REPEAT: return "Repeat New Code";
    case ENTRY:         return "Motion! " + String(entrySecsLeft()) + "s left";
    case ALERT:         return "!! ALERT !!";
    case ARMED:         return lockedOut ? "System Locked" : "System Armed";
    default:            return lockedOut ? "System Locked" : "System Disarmed";
  }
}

String bottomLine() {
  if (state == CONFIRM) return "2 = Real Threat";
  if (lockedOut) return "Wait " + String(lockSecondsLeft()) + " sec";

  if (entered.length() > 0) {
    String shown = entered;
    if (HIDE_CODE) {
      shown = "";
      for (unsigned int i = 0; i < entered.length(); i++) shown += '*';
    }
    return "Code: " + shown;
  }

  switch (state) {
    case ALERT:    return resetRequested ? "Code to Reset" : "Enter Alert Code";
    case DISARMED: return "Code / A=Change";
    case CHANGE_OLD:
    case CHANGE_NEW:
    case CHANGE_REPEAT: return "# = OK  * = Back";
    default:       return "Enter Code";
  }
}

void showStatus() {
  printLine(0, topLine());
  printLine(1, bottomLine());
}

void updateScreenTimers() {
  // Temporary message finished -> back to the normal screen
  if (messageDuration > 0 && millis() - messageStart >= messageDuration) {
    messageDuration = 0;
    if (notifiedPending) {
      notifiedPending = false;
      showMessage("Authorities", "Notified", 3000);
    } else {
      showStatus();
    }
  }

  // Half-typed code timed out
  if (entered.length() > 0 && millis() - lastKeyTime >= ENTRY_TIMEOUT) {
    entered = "";
    showStatus();
  }

  // Lockout finished
  if (lockedOut && millis() - lockoutStart >= lockoutDuration) {
    lockedOut = false;
    if (messageDuration == 0) showStatus();
  }

  // Keep countdowns on screen up to date
  static unsigned long lastRedraw = 0;
  if ((lockedOut || state == ENTRY) && messageDuration == 0 && millis() - lastRedraw >= 250) {
    lastRedraw = millis();
    showStatus();
  }
}

08Code explained

The sketch, one part at a time. Open any section.

The big idea: a loop that never waits loop()

Most beginner sketches use delay(), which freezes the whole Arduino. While it's frozen, keypresses are missed, the siren stops changing pitch and the sensor isn't checked. This sketch never pauses in loop(). Every pass is quick, and each job only does something when it's time to:

void loop() {
  checkButton();        // was the button just pressed?
  checkKeypad();        // was a key just pressed?
  checkSensor();        // time for another distance reading?
  updateEntryDelay();   // entry countdown + warning beeps
  updateSound();        // siren or the next note of a sound effect
  updateLEDs();
  updateScreenTimers(); // put the screen back after a message
}

"Is it time yet?" is checked with millis(), the number of milliseconds since the board started:

if (millis() - lastSensorTime < SENSOR_INTERVAL) return;  // not yet
lastSensorTime = millis();                                  // it's time: remember when

Writing it as millis() - start (rather than comparing to a future time) keeps it working when millis() rolls back to 0 after about 49 days.

States enum State, setState()

Instead of lots of true/false flags, the system has one variable saying what it's doing:

enum State { DISARMED, ARMED, ENTRY, ALERT, CONFIRM, CHANGE_OLD, CHANGE_NEW, CHANGE_REPEAT };

All changes go through setState(), so the side effects happen in one place: the siren stops when leaving an alarm, the timers start, the typed code is cleared and the servo moves.

myServo.write((s == ARMED || s == ENTRY) ? 0 : 90);  // locked while armed

The screen, LEDs and sound all look at state to decide what to show, so they can never disagree with each other.

Keypad and codes handleCodeKey(), submitCode()

checkKeypad() reads one key, plays a click and passes it on. handleCodeKey() deals with the special keys:

  • * clears the typed code (or cancels a code change).
  • A starts a code change, but only while disarmed and with nothing typed.
  • # calls submitCode().
  • Anything else is added to entered, up to 8 characters.

submitCode() is a switch on the current state, because the same code means different things at different times. 1234 disarms while armed, arms while disarmed, and does nothing during the siren unless the button was pressed first.

If you start typing and walk away, updateScreenTimers() clears the half-typed code after 8 seconds.

Wrong codes and lockouts wrongCode()

Each wrong code adds one to failedAttempts. At 3, the keypad locks for a time taken from a list that gets longer each time:

const unsigned long LOCKOUT_TIMES[] = {10000, 30000, 60000};

While lockedOut is true, checkKeypad() plays a low "denied" blip and ignores the key. Nothing else stops: if someone guesses wrong 3 times during the entry countdown, the countdown keeps going and the siren still starts. A correct code resets both the attempts and the lockout level.

Motion sensor checkSensor(), getDistance()

The HC-SR04 sends out a 10 µs ultrasonic "ping" and holds Echo HIGH for as long as the sound took to bounce back. Sound travels about 1 cm every 29 µs, and it goes there and back, so distance in cm = time ÷ 58.

long duration = pulseIn(echoPin, HIGH, 25000);  // give up after 25 ms (~4 m)
if (duration == 0) return -1;                   // no echo
return duration / 58;

The sensor is read every 100 ms, and only when armed and past the 5-second exit delay. A reading under 20 cm adds 1 to closeReadings, and anything else resets it to 0. It takes 3 in a row to start the entry countdown, which filters out random bad readings.

Sounds and the siren PLAY(), updateSound()

Each sound effect is a short list of notes, each with a frequency and a length:

const Note GOOD[] = {{1500, 80}, {2000, 80}, {2600, 120}};  // rising chirp
PLAY(GOOD);

PLAY() starts the first note. On each pass of the loop, updateSound() checks whether that note has finished and starts the next one. The sound plays without stopping anything else.

The siren works out its pitch from the time. Over each second the pitch climbs from 600 to 1600 Hz and falls back:

unsigned long phase = (millis() - alertStart) % 1000;   // 0..999
unsigned int freq = (phase < 500) ? 600 + phase * 2 : 600 + (1000 - phase) * 2;
Saving the code loadCode(), saveCode()

The Uno has 1 KB of EEPROM, memory that keeps its contents with the power off. The code is stored like this:

AddressHolds
0A "magic" byte, 0x42, meaning "a code has been saved here"
1Length of the code (4–8)
2–9The digits

A brand-new board has 0xFF everywhere, so without the magic byte the code would load garbage. EEPROM.update() only writes a byte if it changed, which saves wear (each byte lasts about 100,000 writes).

In setup(), if the button is held at power-on, the code is reset to 1234 and saved.

The screen printLine(), showMessage(), topLine()

lcd.clear() makes the screen flash. printLine() overwrites a line instead and pads it with spaces to 16 characters, so old text never peeks through.

There are two kinds of screen:

  • Status screens, built by topLine() and bottomLine() from the current state (for example System Armed / Enter Code).
  • Messages like Wrong Password, shown by showMessage() for a set time. When the time is up, updateScreenTimers() puts the status screen back.

Countdowns (entry delay and lockout) are redrawn 4 times a second, so the seconds tick down live. notifiedPending lets Calling 911... be followed by a second message, Authorities Notified.

LEDs and button updateLEDs(), checkButton()

updateLEDs() runs every loop and sets both LEDs from the state. The entry-delay blink uses (millis() / 250) % 2, which flips between 0 and 1 every 250 ms.

The button is debounced. A real button "bounces" on and off for a few milliseconds when pressed, so changes within 50 ms of the last one are ignored. It only acts on a press (HIGH → LOW), so holding it down doesn't repeat.

Step 1: Run the self-test

This separate sketch uses the same wiring and checks every part, one at a time. Upload it, open Tools → Serial Monitor at 9600 baud, and watch:

  1. I2C scan. Prints the LCD's address. If it isn't 0x27, change it in both sketches.
  2. LCD. Should show Self-Test OK and 0123456789ABCDEF.
  3. LEDs. Green, then red, each for under a second.
  4. Buzzer. Three tones going up. If they all sound the same, it's an active buzzer.
  5. Servo. Swings 0° → 90° → 0°.
  6. Live test. Every key you press is shown on the LCD and in the Serial Monitor. The bottom line shows the distance. The green LED lights while the button is held, and the red LED lights when something is closer than 20 cm.

// Hardware self-test for the Arduino Keypad Security System.
// Upload this, open the Serial Monitor at 9600 baud, and follow along.
// It checks every part one by one, then runs a live test you can poke at.

#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <Servo.h>
#include <Keypad.h>

// Same pins as the main sketch
const int trigPin   = 10;
const int echoPin   = 11;
const int buzzer    = 12;
const int servoPin  = A3;
const int buttonPin = A2;
const int greenLED  = A0;
const int redLED    = A1;

LiquidCrystal_I2C lcd(0x27, 16, 2);   // change to 0x3F if the scan below finds that
Servo myServo;

const byte ROWS = 4;
const byte COLS = 4;
char keys[ROWS][COLS] = {
  {'1','2','3','A'},
  {'4','5','6','B'},
  {'7','8','9','C'},
  {'*','0','#','D'}
};
byte rowPins[ROWS] = {9, 8, 7, 6};
byte colPins[COLS] = {5, 4, 3, 2};
Keypad keypad = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS);

void setup() {
  Serial.begin(9600);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(buzzer, OUTPUT);
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(greenLED, OUTPUT);
  pinMode(redLED, OUTPUT);

  Serial.println(F("=== Security System Self-Test ==="));

  // 1. I2C scan: finds the LCD's address
  Serial.println(F("[1] Scanning I2C bus..."));
  Wire.begin();
  byte found = 0;
  for (byte addr = 1; addr < 127; addr++) {
    Wire.beginTransmission(addr);
    if (Wire.endTransmission() == 0) {
      Serial.print(F("    Found device at 0x"));
      if (addr < 16) Serial.print('0');
      Serial.println(addr, HEX);
      found++;
    }
  }
  if (found == 0) {
    Serial.println(F("    Nothing found! Check SDA->A4, SCL->A5, VCC->5V, GND->GND."));
  }

  // 2. LCD
  Serial.println(F("[2] LCD: should say 'Self-Test OK'"));
  lcd.init();
  lcd.backlight();
  lcd.print(F("Self-Test OK"));
  lcd.setCursor(0, 1);
  lcd.print(F("0123456789ABCDEF"));
  delay(1500);

  // 3. LEDs
  Serial.println(F("[3] Green LED on"));
  digitalWrite(greenLED, HIGH);
  delay(800);
  digitalWrite(greenLED, LOW);
  Serial.println(F("    Red LED on"));
  digitalWrite(redLED, HIGH);
  delay(800);
  digitalWrite(redLED, LOW);

  // 4. Buzzer: three rising tones (a passive buzzer changes pitch, an active one won't)
  Serial.println(F("[4] Buzzer: low, middle, high tone"));
  tone(buzzer, 500, 250);  delay(350);
  tone(buzzer, 1000, 250); delay(350);
  tone(buzzer, 2000, 250); delay(350);

  // 5. Servo
  Serial.println(F("[5] Servo: 0 -> 90 -> 0 degrees"));
  myServo.attach(servoPin);
  myServo.write(0);   delay(600);
  myServo.write(90);  delay(600);
  myServo.write(0);   delay(600);

  Serial.println(F("[6] Live test: press keys, press the button, wave at the sensor."));
  Serial.println(F("    Green LED = button held, Red LED = something under 20 cm."));
  lcd.clear();
  lcd.print(F("Press a key..."));
}

void loop() {
  // Keypad
  char key = keypad.getKey();
  if (key) {
    Serial.print(F("Key: "));
    Serial.println(key);
    tone(buzzer, 2000, 30);
    lcd.setCursor(0, 0);
    lcd.print(F("Key: "));
    lcd.print(key);
    lcd.print(F("          "));
  }

  // Button
  static bool lastButton = HIGH;
  bool button = digitalRead(buttonPin);
  digitalWrite(greenLED, button == LOW ? HIGH : LOW);
  if (button != lastButton) {
    lastButton = button;
    Serial.println(button == LOW ? F("Button: PRESSED") : F("Button: released"));
  }

  // Ultrasonic sensor
  static unsigned long lastPing = 0;
  if (millis() - lastPing >= 500) {
    lastPing = millis();
    long distance = getDistance();
    digitalWrite(redLED, (distance > 0 && distance < 20) ? HIGH : LOW);

    lcd.setCursor(0, 1);
    lcd.print(F("Dist: "));
    if (distance < 0) lcd.print(F("--"));
    else lcd.print(distance);
    lcd.print(F(" cm      "));

    Serial.print(F("Distance: "));
    if (distance < 0) Serial.println(F("no echo"));
    else { Serial.print(distance); Serial.println(F(" cm")); }
  }
}

long getDistance() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  long duration = pulseIn(echoPin, HIGH, 25000);
  if (duration == 0) return -1;
  return duration / 58;
}

11Notes & ideas

Limits, safety, and where to take it next.

Limitations

  • It doesn't really call 911. "Calling 911..." is only a message. The Uno has no internet or phone connection.
  • It's a learning project, not a real alarm. Unplugging it turns it off, and the board and button are reachable.
  • The sensor only sees straight ahead, in a cone about 15° wide. Soft things like clothes can absorb the sound and not be seen.
  • Codes are stored in plain text in EEPROM, and anyone who can hold the button at power-on can reset them.

Ideas for upgrades

  • Event log: print every arm, disarm and alarm to the Serial Monitor with a timestamp.
  • Real notifications: swap the Uno for an ESP32 and send a phone notification when the alarm goes off.
  • Real clock: add a DS3231 RTC module to record when each alarm happened.
  • More sensors: a PIR motion sensor or a magnetic door switch on D13.
  • Battery backup so pulling the plug doesn't silence it.
  • Hide the code as it's typed: set HIDE_CODE = true.

Memory use

The Uno has only 2 KB of RAM. This sketch uses String for codes and messages, which is easy to read but uses more memory than plain character arrays. If you add lots of features and the board starts acting strangely, look at the RAM figure the IDE prints after compiling. Above about 75%, wrap fixed text in F("...") so it stays in flash memory.

Project history

  • Started with a basic arm/disarm keypad, LCD, LEDs, buzzer and servo.
  • Fixed the keypad pin order (the ribbon was reversed).
  • Added clear LCD messages and the alert code with false alarm / real threat.
  • Fixed messages longer than 16 characters, and a bug that showed the alert code on screen.
  • Rewrote it to never use delay() in the loop, so the siren and sensor keep working during messages and lockouts.
  • Added the entry delay, the reset button needing a code, a changeable code saved in EEPROM, sound effects, longer lockouts and the siren.
